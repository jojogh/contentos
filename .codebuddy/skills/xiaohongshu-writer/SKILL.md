# 小红书写作技能 v1.1

专业小红书内容创作助手，从选题到发布全流程指导。

> **v1.1 更新**：新增封面自动生成（4风格×5配色）、违规词库动态更新（7天周期自动拉取）

## 工作流程决策树

```
用户需求 → 判断阶段
├── "帮我想选题" / "写什么好" → 【选题策划】
├── "帮我写小红书" / "怎么写爆款" → 【模板选择】→ 【内容创作】
├── "生成封面" / "做个封面图" → 【封面生成】
├── "这样写会不会违规" / "敏感词检测" → 【违规检测（动态词库）】
└── "什么时候发" / "标签怎么写" → 【发布优化】
```

## 输出格式规范（重要）

> ⚠️ **小红书不支持Markdown语法**，所有输出必须使用小红书原生格式

### 格式要求

| 禁止使用 | 正确做法 |
|---------|---------|
| `# 标题` | 用emoji开头，如 `🔥 标题` |
| `### 小标题` | 用 `【小标题】` 格式 |
| `**加粗**` | 直接写文字，用emoji强调 |
| `| 表格 |` | 用列表形式：`• 项目：说明` |
| `> 引用` | 用换行或emoji分隔 |
| `- 列表` | 用 `• ` 符号 |

### 标准输出模板

```
🔥 主标题（emoji开头）

【小标题1】

• 要点一
• 要点二
• 要点三

【小标题2】

内容段落，换行分段。

• 列表项一
• 列表项二

【总结】

结论或引导互动。

#话题标签
```

### 对比示例

❌ **错误（Markdown格式）：**
```
### 核心功能
**特点**：很好用
| 项目 | 说明 |
|------|------|
| 价格 | 便宜 |
```

✅ **正确（小红书原生格式）：**
```
【核心功能】

特点：很好用

• 价格：便宜
• 质量：靠谱
```

## 一、选题策划

### 爆款选题公式

**热点 + 痛点 + 情绪 = 爆款潜力**

| 选题类型 | 公式 | 示例 |
|---------|------|------|
| 痛点型 | 「问题」+「解决方案」 | 皮肤暗沉怎么办？这3招让你白成一道光 |
| 对比型 | 「A vs B」+「结论」 | 300块vs3000块精华，差的原来是这个 |
| 清单型 | 「数字」+「主题」+「价值」 | 10个相见恨晚的淘宝好店，第5个绝了 |
| 故事型 | 「冲突」+「转折」+「收获」 | 月薪3k到3w，我只做对了这件事 |
| 教程型 | 「成果」+「步骤拆解」 | 0基础学插画，7天画出第一张作品 |

### 选题来源

1. **热点追踪**：微博热搜、抖音热榜、小红书发现页
2. **用户痛点**：评论区高频问题、搜索下拉词
3. **竞品分析**：同类爆款笔记的选题延伸
4. **季节节点**：节日、换季、开学季等时间节点

### 选题验证

- [ ] 这个话题有人搜吗？（搜索量验证）
- [ ] 这个话题有爆款吗？（对标笔记分析）
- [ ] 我能写出差异化吗？（切入点独特性）

## 二、模板选择

### 标题模板库

**核心公式：情绪词 + 利益点 + 数字/疑问**

```
【数字型】
• ___天，我实现了___（时间+成果）
• 亲测___款___，只有这___款值得买（测评类）
• ___个___，第___个绝了（清单类）

【疑问型】
• 为什么___？答案竟然是___
• ___真的有用吗？亲测___天告诉你
• 谁说___？我___（反常识）

【对比型】
• ___vs___，差的不只是价格
• 以前___，现在___，只因做对了___

【情绪型】
• 终于___了！后悔没早点___
• 姐妹们！这个___一定要知道！
• 相见恨晚！___竟然可以这样用

【警告型】
• 千万别___！否则___
• ___前一定要知道的___件事
• 别再___了！正确做法是___
```

### 正文结构模板

**种草型结构**
```
【开头】痛点引入 + 共情
"有没有姐妹和我一样___"

【中间】产品/方法介绍
• 产品信息：品牌、价格、购买渠道
• 使用体验：具体场景 + 真实感受
• 效果对比：使用前后对比（配图更佳）

【结尾】总结 + 引导互动
"用了___天，真的___"
"姐妹们还有什么___，评论区告诉我～"

【标签】#相关话题
```

**教程型结构**
```
【开头】成果展示 + 权威背书
"今天分享我___的方法，亲测有效！"

【正文】步骤拆解（每步配图）
Step 1: ___
Step 2: ___
Step 3: ___

【结尾】注意事项 + 互动引导
"几个小tips：___"
"有问题评论区问我～"
```

**测评型结构**
```
【开头】测评背景 + 选品逻辑
"为了找到最好的___，我买了___款"

【正文】逐一测评（每个产品一段）

• 产品名称
  价格：___
  优点：___
  缺点：___
  推荐指数：⭐⭐⭐⭐

• 产品名称
  ...

【结尾】综合推荐
"总结：___最适合___"
"预算有限选___，追求品质选___"
```

## 三、封面生成 ← v1.1 新增

### 自动封面生成

使用 `scripts/generate_cover.py` 自动生成小红书标准封面（1080×1440px，3:4竖版）。

```bash
python scripts/generate_cover.py --title "月薪3k到3w" --style emoji --palette macaron
```

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--title, -t` | 封面主标题（≤8字效果最佳） | 必填 |
| `--subtitle, -s` | 副标题 | 无 |
| `--style, -y` | 风格：emoji / text / contrast | emoji |
| `--palette, -p` | 配色：morandi / macaron / premium / warm / fresh | macaron |
| `--output, -o` | 输出路径 | cover.png |

### 封面风格选择

| 风格 | 视觉特点 | 适用场景 |
|------|---------|---------|
| `emoji` | 渐变背景 + emoji装饰 + 大字居中 | 种草好物、生活分享 |
| `text` | 纯色背景 + 装饰线 + 简约排版 | 知识干货、经验分享 |
| `contrast` | 上下分色 + 标签式高亮 | 测评对比、前后反差 |

### 配色方案

| 方案 | 色调 | 适用内容 |
|------|------|---------|
| `macaron` | 粉蓝暖色系 | 美妆、生活、好物 |
| `morandi` | 莫兰迪灰调 | 文艺、设计、家居 |
| `premium` | 深色高对比 | 科技、商务、测评 |
| `warm` | 暖粉渐变 | 情感、故事、日常 |
| `fresh` | 清新绿系 | 健康、食品、运动 |

### 封面设计原则

- 标题控制在 8 字以内，超过会自动换行
- 字体自动加载微软雅黑（Windows）
- 输出为 PNG 格式，1080×1440 像素
- 可反复生成不同风格对比选择

## 四、违规检测（动态词库） ← v1.1 升级

### 动态词库机制

> 违规词库不再静态固定，每 **7天** 自动从在线源拉取最新词汇并更新。

```bash
# 查看当前词库状态
python scripts/compliance_updater.py --status

# 强制立即更新词库
python scripts/compliance_updater.py --force

# 常规检查（超过7天才更新）
python scripts/compliance_updater.py
```

**工作原理：**
1. 从 GitHub 开源敏感词库拉取最新词汇
2. 合并到本地缓存（`references/compliance_cache.json`）
3. 自动重新生成 `references/compliance.md`
4. 同步更新 `check_compliance.py` 支持动态词加载

**更新周期配置：**
- 自动更新阈值：7 天（`MAX_CACHE_AGE_DAYS`）
- 完全重建阈值：30 天（`MAX_STALE_DAYS`）
- 修改 `scripts/compliance_updater.py` 顶部的常量可调整

### 内容安全检查清单

- [ ] 无医疗功效承诺（治疗、治愈、根治）
- [ ] 无绝对化用语（第一、最好、顶级）
- [ ] 无引导站外交易（微信号、二维码、链接）
- [ ] 无敏感政治话题
- [ ] 无虚假宣传（功效需有依据）
- [ ] 图片无水印、无马赛克遮挡
- [ ] **动态词库已更新（7天内）** ← v1.1 新增

### 违规检测

使用 `scripts/check_compliance.py` 自动检测（已支持动态词库）：

```bash
python scripts/check_compliance.py "你的笔记内容"
python scripts/check_compliance.py -f 文件路径
```

### 常见违规词替换

详见 [references/compliance.md](references/compliance.md) 完整违规词库（动态更新）

| 违规词 | 替代词 |
|-------|-------|
| 第一、最好 | 之一、推荐、亲测好用 |
| 治愈、根治 | 改善、缓解、帮助 |
| 瘦身、减肥 | 塑形、身材管理 |
| 美白、祛斑 | 提亮、均匀肤色 |
| 绝对、一定 | 可能、也许、大概率 |
| 点击链接 | 详见主页、dd私聊 |

## 五、发布优化

### 发布时间建议

| 时间段 | 推荐指数 | 适合内容 |
|-------|---------|---------|
| 7:00-9:00 | ⭐⭐⭐⭐ | 早餐、穿搭、晨间护肤 |
| 12:00-14:00 | ⭐⭐⭐⭐⭐ | 美食、午休、搞笑 |
| 18:00-20:00 | ⭐⭐⭐⭐⭐ | 下班、晚餐、健身 |
| 21:00-23:00 | ⭐⭐⭐⭐⭐ | 护肤、情感、生活方式 |

### 标签策略

**黄金组合：1个大词 + 2-3个中词 + 2个长尾词**

```
示例（护肤类）：
#护肤（大词，流量大竞争大）
#护肤心得 #干皮护肤（中词，流量适中）
#干皮亲测 #平价护肤推荐（长尾词，精准转化）
```

**标签数量：5-10个为宜**

### 发布后运营

1. **黄金30分钟**：及时回复评论，提升互动率
2. **数据监控**：观察收藏、点赞、评论比例
3. **二次传播**：同步到其他平台（微博、抖音）
4. **笔记优化**：根据数据调整标题、封面

## 六、实战工作流

### 完整创作流程（v1.1）

```
1. 确定选题
   ↓
2. 选择模板 → 参考 [references/templates.md](references/templates.md)
   ↓
3. 撰写内容 → 标题 + 正文 + 标签
   ↓
4. 更新违规词库（超过7天）→ python scripts/compliance_updater.py
   ↓
5. 违规检测 → 运行 scripts/check_compliance.py
   ↓
6. 生成封面 → python scripts/generate_cover.py  ← v1.1 新增
   ↓
7. 选择发布时间 → 参考时间段建议
   ↓
8. 发布 + 互动 → 及时回复评论
```

### 快速检查表

发布前最后确认：

- [ ] 标题：有情绪词 + 数字/疑问？
- [ ] 正文：结构清晰，段落短？
- [ ] 违规词：已检测无问题？（词库7天内更新？）
- [ ] 封面：3:4比例，风格匹配？（← v1.1 新增）
- [ ] 标签：5-10个，有大词+长尾？
- [ ] 发布时间：黄金时段？
