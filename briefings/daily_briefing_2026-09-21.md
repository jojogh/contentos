### 1. [xiaohongshu] TikTok Shop 开始罚 AI 素材了:我把工作流改成合规版,只动了 3 个环节

- **形式**：case-study　|　**Hook 模式**：元模式 1「实测了 X,结果…」　|　**目标字数**：500
- **标签**：TikTok Shop、AI 素材、合规、跨境电商、工作流
- **素材来源**：tiktok-shop-ai-content-crackdown、capcut-xiaoying-agent

先说结论:AI 视频不是不能用,是不能「全靠 AI」。

上周看到一组数据,印象很深——TikTok Shop 这轮收紧之后,有人算了笔账:一条 AI 视频的成本不到真人拍摄的十分之一,单条能省 100 到 200 块。但被处罚的账号里,有月销 20 万美元级别的。

省的是线性成本,赔的是非线性风险。这两个数放在一起,你会发现「AI 出片省多少钱」这个算法少了另一半。

我把自己的工作流拆了一遍,发现只需要动 3 个环节,就能把风险压下来。

**一、把镜头分成两类,而不是分成「能省」和「不能省」**

我现在按「观众会不会认为是假的」来分,不按成本分:

必须真人拍的:真人出镜口播、产品实际使用、开箱、任何需要证明「这个东西真实存在」的镜头。

可以交给 AI 的:场景铺陈、氛围镜头、多语言版本、同一素材的批量变体。

分界线很清楚——**镜头里有没有一个需要被相信的「人」或「物」**。有,就真人;没有,AI 随便跑。

**二、给 AI 素材留一个可验证的锚点**

纯 AI 生成的画面有个特征:没有任何可被核实的信息。我在每条 AI 素材里强制加一个真实元素——真实的产品包装、真实的使用场景截图、或者一个真人手部动作。

这不是为了骗过审核,而是让素材本身经得起看。平台的判罚逻辑通常是「这条内容是否真实反映商品」,有一个真实锚点,你就站在说得清的那一侧。

**三、出片速度和审片速度要匹配**

这是最容易忽略的一点。剪映刚发的「小映」能把多轨剪辑交给 Agent,批量出片速度上来了,但如果你的审片还是人工一条条看,产能全卡在最后一步。

我的做法是给 AI 素材定三条硬规则(时长区间、必含元素、禁止出现的内容),用规则先筛一遍,人只看通过规则的那一批。

**说回成本**

改造完之后我的单条成本大概是纯 AI 方案的 1.6 倍,但比全真人拍摄还是低很多。

更重要的是:我不再需要每天担心哪个账号明天会没。

如果你也在用 AI 出素材,建议先做第一步——把手上所有镜头按「有没有需要被相信的人或物」过一遍。这一步 10 分钟就能做完,但它会告诉你,你的风险敞口到底有多大。

### 2. [wechat] Sora 2 API 说停就停:3 天迁移清单,和一次关于「依赖」的复盘

- **形式**：deep-dive　|　**Hook 模式**：元模式 2「X 刚发布/更新了,对你意味着三件事」　|　**目标字数**：2000
- **标签**：Sora 2、API 关停、迁移、AI 视频、供应链风险
- **素材来源**：sora2-api-shutdown-0924、minimax-h3-fashion-film

9 月 24 日,Sora 2 API 关停。

不是降级,不是限量,是关停——sora-2、sora-2-pro 以及全部快照版本一起下线,而且没有公布 Sora 3 或任何继任 API。

如果你已经把 Sora 2 接进了广告素材产线,你现在有 3 天。

**先把这件事定性:这不是技术问题,是供应链问题**

模型 API 和云服务一样,本质是供应链。区别在于,云厂商关停一个服务通常会提前一年公告、给迁移工具、提供等价替代;而模型 API 的关停可以只给几天,且不承诺继任者。

过去两年我们习惯了「模型越来越强、越来越便宜」的叙事,容易忘掉另一半:供给方随时可以退出。

所以这篇不谈「AI 视频哪家强」,谈一件更实际的事——你的产线里有多少东西是单点依赖。

**迁移清单:今天就能执行的 4 步**

**第一步:盘点调用面(约 30 分钟)**

把所有还在调用 sora-2 / sora-2-pro 的地方列出来。注意三个容易漏的角落:

- 自动化脚本和定时任务里硬编码的模型名
- 素材生成平台里配好的「默认视频模型」
- 第三方向你交付、但你不知道它底层用了什么的部分(这个通常问不出来,先标记)

盘点完你会知道真实的影响面。我的经验是:人记得的调用点通常是实际数量的一半。

**第二步:检查 prompt 的可移植性(约半天)**

这一步最容易低估。你为 Sora 2 调好的提示词,移植到别的模型上大概率不会直接工作——镜头语言、参数格式、对「秒数」和「比例」的表达方式,各家都不一样。

取 5 条你最常用的 prompt,在候选模型上各跑一遍,记录:出片是否可用、需要改多少、改完之后效果是否稳定。这 5 条样本会告诉你迁移的真实工作量,比任何评测榜都准。

**第三步:跑一批对照素材(约 1 天)**

目前公开信息里,Seedance 2.0 在图像转视频竞技场以 1,344 Elo 居首。但榜单第一不等于你的场景第一。

用你真实的商品素材跑一批对照:同一批产品图,分别用 Seedance、Kling、Veo 生成,然后让不参与制作的人盲评。判断标准不是「哪个更好看」,是**「哪个更少需要返工」**。

顺便说一个参考:最近有一条用 MiniMax H3 做的时装影片,8 套造型 8 个场景一次生成,质量已经能进品牌向内容。也就是说,服装类目的替代方案基本成熟——但造型一致性仍然需要人工校验。

**第四步:重算单位成本(约 1 小时)**

不要只比单价。算这个数:**「一条可用素材的完整成本」= 生成成本 + 返工次数 × 单次生成成本 + 人工挑选时间**。

很多模型单价便宜但可用率低,算完总账反而更贵。这一步做完,迁移决策基本就清楚了。

**比迁移更重要的一件事**

迁移完,建议顺手做一件事:给所有模型依赖加一层抽象。

具体说,就是不要让业务代码直接写模型名。中间加一层你自己的接口,把「生成一条 5 秒竖版视频」定义成你自己的动作,底层用哪家模型变成配置项。

这次迁移你花了 3 天,下次可能只花 3 小时。

**一个判断**

Sora 2 关停这件事,最值得记住的不是「又少了一个模型」,而是它把「AI 能力是稳定基础设施」这个假设打破了。

模型会关停、会涨价、会改接口。真正抗风险的产线,不是建在最强模型上的那条,是**换模型成本最低的那条**。

这一点和做跨境电商是同一个道理——你不会把全部库存压在一个渠道上。

### 3. [x] 7B 跑赢 Opus 5:垂直 Agent 的成本天花板从来不在 API 单价上

- **形式**：news-commentary　|　**Hook 模式**：元模式 3「大部分人用 X 的方式是错的」　|　**目标字数**：400
- **标签**：Agent、小模型、自我蒸馏、成本、垂直场景
- **素材来源**：7b-self-distillation-prediction-market、stepfun-step5-preview

一个 7B 模型,在预测市场任务上跑赢了 GPT-5.6 和 Opus 5。

清华背景的初创团队 + UIUC,方法是自我蒸馏:让模型在自己的输出上反复筛选、再训练。论文口径,单任务,未独立复现——但方向值得认真看。

**这条为什么比「API 又降价了」重要**

降价是别人替你降的成本。你只是受益者,而且谁都能受益——你的竞争对手拿到的是同一个价目表。

而模型规模的下降,降的是整个量级,不是单价。

**把三种省钱方式分开看**

① 换更便宜的旗舰
阶跃 Step 5 Preview,600B 总参数 / 激活 27B,厂商称单任务成本是 Opus 5 的 1/8(首批独立实测刚开始出现)。省的是单位 token 成本。

③ 换更小的模型
省的是整个量级。

前两条今天就能用,第三条要的是你自己的数据闭环:哪些样本算好、哪些算坏、用什么标准筛。这套标准没人能卖给你。

**所以问题不是「该用哪个模型」**

是「你有没有一套能判断输出好坏的机制」。有,你就能用 7B 干 200B 的活;没有,你换到再便宜的旗舰也只是在替厂商消化产能。

如果你在做垂直 Agent,先把第③条想清楚。前两条会自己发生。
