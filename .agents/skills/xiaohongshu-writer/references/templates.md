## 三、爆款结构分析

### 黄金开头公式

| 类型 | 公式 | 示例 |
|-----|-----|-----|
| 痛点型 | 问题+共情 | 有没有人和我一样... |
| 好奇型 | 悬念+结果 | 我用这个方法... |
| 权威型 | 身份+成果 | 从业5年，告诉你... |
| 对比型 | 前后反差 | 以前以为...现在... |

### 黄金结尾公式

| 类型 | 公式 | 示例 |
|-----|-----|-----|
| 互动型 | 提问+引导 | 你们觉得呢？评论区聊聊 |
| 引导型 | 行动召唤 | 想了解的dd我 |
| 福利型 | 价值+收藏 | 建议收藏，以后用得上 |
| 总结型 | 要点回顾 | 记住这3点就够了 |

## 四、行业模板

### 美妆护肤

```
标题公式：肤质+问题+解决方案
正文结构：肤质介绍→产品使用→效果对比→注意事项
配图建议：使用前后对比图
```

### 穿搭时尚

```
标题公式：风格/场合+单品+搭配公式
正文结构：单品介绍→搭配思路→穿搭示范→购买信息
配图建议：全身搭配图+细节特写
```

### 美食探店

```
标题公式：店名/菜品+亮点+推荐度
正文结构：店铺信息→环境描述→菜品点评→人均消费
配图建议：环境图+菜品特写
```

### 旅行攻略

```
标题公式：目的地+天数+亮点
正文结构：行程概览→每日安排→交通住宿→注意事项
配图建议：风景图+打卡点
```

### 家居好物

```
标题公式：空间/需求+好物+使用体验
正文结构：购买背景→产品介绍→使用感受→推荐理由
配图建议：场景图+细节图
```
