## 逐项核对记录

- **U1 / 表结构**：`xl/workbook.xml` + `xl/_rels/workbook.xml.rels` 确认五张表及其映射：近两年销售趋势→sheet1、价格段分析→sheet2、竞品清单→sheet3、评论清单→sheet4、利润核算→sheet5。
- **U1 / 列数**：竞品清单表头单元格 A→CI，计 87 列；其中匹配 `20\d\d-\d\d` 的月份字段 48 个，起 2024-09、止 2026-08，即 24 个月 × 2（销量、销售额）。
- **U1 / 行数**：sheet3 共 259 个 row 节点，前 2 行为表头与备注，A 列为纯数字的数据行 257 行。
- **U1 / 数据质量字段**：销售趋势表头含「销量有效记录数」「销售额有效记录数」；竞品清单含 AJ「近12月销量有效月数」、AK「前12月销量有效月数」、AL「近12月销售额有效月数」、AM「前12月销售额有效月数」；价格段表含 I「24月完整商品数」。
- **U1 / C3 计算**：对 257 行取 AJ 列做频次统计，`12`→144 行、`3`→23、`1`→22、`4`→12、`2`→10、`0`→10、`10`→7、`11`→6，其余为 5/6/7/8/9。
- **U1 / 利润核算**：sheet5 仅 1 个 row 节点、1 个单元格，内容为「人工做，不让codex来整理」。
- **U1 / 价格段表公式**：合计行 F15、G15 为 `IF(E15>0,C15/E15-1,"n.a.")` 与 `IF(F15>0,D15/F15-1,"n.a.")`；B15、I15 分别为 `SUM(B6:B14)`、`SUM(I6:I14)`。销售趋势表（sheet1）全表无公式。
- **U1 / 备注行**：竞品清单表头下备注写明「以上内容来自卖家精灵-竞品查询中导出」「以上内容从竞品图片、页面卖点信息内获取，摘取时每10个asin一批，分批进行，并且要做复核」「每个父asin下仅保留月销量数据最高的那个子asin」；价格段表备注为「数据由后面的竞品清单信息进行汇总，价格段让codex来自行划分」；评论清单备注写明需覆盖竞品清单前百 ASIN、每条评论须能对应父 ASIN、翻译须用可下载离线模型且为润色而非机翻。
- **U2 / 结构**：正文 149 个非空段落，六部分为「销售趋势分析 / 价格段分析 / 竞品清单分析 / 评论清单分析 / 表格中缺少的两个重要分析环节（用户画像、应用场景）/ 最终表格输出方式」。
- **U2 / C5**：第六部分表格表头为四列（数据来源、Codex分析结果与通俗解释、结论、建议方向），数据行五行，末行为「用户画像与应用场景」。
- **U1,U2 / C9（亚马逊属性）**：竞品清单表头含 C=ASIN、L=父ASIN、M=变体数、S=FBA($)、AA=包装尺寸分段、W=卖家所属地；备注行原文「以上内容来自卖家精灵-竞品查询中导出」。需求文档第三部分「已分析内容」首项为「ASIN清单」。正文只陈述这些字段与出处，未指定具体站点——模板内没有站点字段，$ / USD 仅出现在价格与销售额列名中，不足以断定市场站点。
