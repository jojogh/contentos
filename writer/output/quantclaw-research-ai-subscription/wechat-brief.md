## 适用边界

- 适用：需要同时使用国产与海外模型、希望通过 Claude Code / Codex 等 agent 客户端开展工作的科研团队
- 不适用：涉密项目、未通过学校审批的高敏感数据、只需要单一模型且已有稳定采购渠道的团队
- 最强反方：多模型订阅可能带来供应商锁定、额度不透明、数据合规和模型版本漂移；平台聚合不等于能力保证
- 本文如何回应：单列“试用前先确认的四件事”，并明确平台信息来自试用说明，具体以平台发放为准
