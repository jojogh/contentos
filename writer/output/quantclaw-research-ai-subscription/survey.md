# 问卷内容（三版）

配套文章：《AI 科研，实验室真正缺的不是模型，而是一个统一入口》
用途：替换正文中的 `[问卷链接或二维码，发布前替换]` 占位符。
建议平台：问卷星 / 金数据 / 腾讯问卷，均为单选、多选、填空、评分四种题型。

---

## 版本 A：试用申请（最短，5 题，约 40 秒）

> 标题：QuantClaw 科研试用申请
> 说明：填完后我们会通过你留下的邮箱发放试用 token 和连接方式。约需 40 秒。

1. **怎么称呼你？**（填空，必填）
   - 示例：张老师 / 王同学

2. **你所在的单位与课题组**（填空，必填）
   - 示例：××大学 材料学院 ×× 课题组

3. **你的身份**（单选，必填）
   - 教师 / PI
   - 博士后
   - 研究生
   - 科研信息化或实验室管理
   - 其他

4. **目前常用哪些模型？**（多选，必填）
   - DeepSeek
   - Kimi
   - Claude
   - ChatGPT / GPT
   - 文心 / 通义 / 智谱等国内模型
   - 基本还没用
   - 其他

5. **邮箱（用于发放试用 token 和连接方式）**（填空，必填）
   - 请填写常用邮箱，发放后 3 个工作日内查收

可选补充一题（建议加分，不必填）：**你最想先用 AI 做哪件事？**（填空）

## 版本 B：需求调研（7 题，约 2 分钟）

> 标题：科研团队用 AI，卡在哪一步？
> 说明：5 分钟以内，帮我们判断试用怎么发、文档怎么写。不会对外公开。

1. **你的身份**（单选，必填）
   - 教师 / PI　- 博士后　- 研究生　- 科研信息化 / 实验室管理　- 其他

2. **课题组大约多少人？**（单选，必填）
   - 1-5 人　- 6-15 人　- 16-30 人　- 30 人以上

3. **现在用 AI 主要卡在哪一步？**（多选，最多选 3 项，必填）
   - 账号注册与验证
   - 付费、开票、走经费
   - API key 和客户端配置
   - 不知道哪个模型适合哪个任务
   - 结果不稳定、难以复现
   - 学校对数据和合规有要求
   - 暂时没遇到明显问题

4. **最想先跑通哪类任务？**（多选，必填）
   - 文献阅读与综述
   - 数据处理与代码
   - 论文写作与润色
   - 实验设计与方案讨论
   - 组内知识库 / 问答
   - 其他

5. **经费通常走哪个科目？**（单选，必填）
   - 科研经费（材料 / 测试 / 计算）
   - 设备或软件采购
   - 院系 / 实验室公共经费
   - 个人自付
   - 还不确定

6. **团队对数据合规的要求**（单选，必填）
   - 只能处理公开数据
   - 可以处理未发表但非涉密数据
   - 有校内审批流程，需先确认
   - 不清楚，需要指引

7. **是否愿意用一个小任务做次评测？**（单选）
   - 愿意，愿意反馈结果
   - 先看看文档再说
   - 暂时不需要

（可选）**希望试用文档里必须写清楚什么？**（填空）

## 版本 C：试用后反馈（5 题，约 1 分钟）

> 标题：试用体验反馈
> 说明：只问使用感受，不收集研究内容。约 1 分钟。

1. **试用期间跑通了哪个任务？**（单选，必填）
   - 文献阅读 / 综述
   - 数据处理 / 代码
   - 写作 / 润色
   - 其他
   - 还没跑通

2. **连接和配置是否顺利？**（评分 1-5，必填）
   - 1 = 卡住了　5 = 一次跑通

3. **耗时与成本符合预期吗？**（单选，必填）
   - 比预期好
   - 基本符合
   - 比预期差
   - 还没法判断

4. **最大的障碍是什么？**（多选，必填）
   - 文档不够清楚
   - 额度或计费不明白
   - 模型选择拿不准
   - 结果不稳定
   - 合规或审批
   - 没有明显障碍

5. **会推荐给同组的人吗？**（单选，必填）
   - 会　- 可能会　- 不会

（可选）**一条最想提的建议**（填空）

## 使用提示

- 三版可并行：A 挂在正文 CTA，B 挂在文末"参考资料"之前或菜单栏，C 在发放试用 7 天后邮件推送。
- 必填项控制在 5 题以内，否则手机端完成率会明显下降。
- 不要问研究内容、涉密方向、具体论文题目；反馈版明确写"不收集研究内容"。
- 版本 A 的第 5 题邮箱是发 token 的唯一通道，需在表单里开启格式校验。
- 问卷里不要出现"数据不出境""合规保证""速度更快"等承诺性表述，与正文口径一致。
