# 小红书图文视觉方案

## 回答摘要与生成假设

- 目标受众：正在做亚马逊选品、产品开发、竞品调研的卖家与产品经理
- 核心观点：竞品分析的第一步不是看竞品有什么，而是先看用户在差评里抱怨什么
- 传播目标：收藏 + 建立专业度
- 情绪曲线：被戳中（顺序反了）→ 获得框架（三档评分）→ 想收藏（三张表）→ 冷静（边界）→ 可执行（今天就做）
- 推荐风格：深色科技杂志风 + 荧光绿强调，沿用账号既有轮播视觉
- 禁止项：廉价蓝紫渐变、PPT 列表感、虚构数据、具体品牌与外部链接
- 我将按以下假设生成：方法优先，7 页，所有具体数字都来自原文的「20 条评论」「约七成」「4-7 个痛点」；不出现真实 ASIN、销量或评论引用

## 风格判断报告

- 内容类型：方法论 / 工具拆解型
- 传播目标：收藏优先，其次建立专业度
- 读者情绪：好奇 + 被击中 + 想立刻试
- 信息密度：中高
- 主风格：深色科技杂志风
- 辅助风格：架构图 / 系统拆解风；结尾用清单式行动页
- 不建议：白底杂志风（冲击力不足）、Notion 卡片风（容易像教程 PPT）、反差冲击封面风（会削弱方法论的可信度）

## 统一视觉母版

- 画布：1080x1440px，严格 3:4 竖版
- 安全边距：左右 72px，上下 80px
- 网格：12 列，8px 基准间距
- 标题区：顶部 18%-32%；封面可到 35%-45%
- 正文区：每页最多 2-4 行主文案，说明不超过 3 个短模块
- 页码：右下角，18px，低对比
- 色彩令牌：背景 #0D0F12；主文字 #F2F3F5；辅助文字 #9BA0A8；强调 #C8F04A；分隔线 #2A2E35
- 字体：中文标题用粗黑体（微软雅黑 / 思源黑体），英文注释用 Inter / 等宽字体
- 组件语言：1px 细线、8px 圆角卡片、无阴影、无渐变；强调色只用于关键词、编号、状态和连线
- 节奏规则：每页只改变主视觉和信息结构，不改变画幅、边距、字体系统和页码位置

## Page 01｜封面

- 页面目标：用一个具体数字和一句反常识判断让人停住
- 主标题：20 条差评
- 副标题：比一份竞品报告更能决定下一版做什么
- 核心文案：先把最近 20 条评论按星级摊开，只盯差评和中评里的高频抱怨
- 视觉构图：左侧巨型数字「20」，右侧 4x3 机会矩阵，只有一个绿色高亮空格
- 情绪目标：好奇 + 「原来顺序错了」
- 信息密度：低
- 图像生成提示词（记录）：深色科技杂志封面，1080x1440，3:4 竖版，深黑底细网格，左侧 380px 巨型荧光绿数字 20，下方中文大标题，右侧低对比 4x3 矩阵卡片，其中一格荧光绿描边，整体克制留白
- 负面提示词：no square, no landscape, no cheap purple gradient, no random neon, no distorted text, no cluttered layout
