| 来源 | 说明 | 使用方法 |

```
• 《狂飙》热播 → "剧中的职场潜规则"（职场）
```

## 四、爆款选题公式

### 对比型选题

```
• ___岁vs___岁，差距竟然这么大
• 月薪___vs月薪___的生活
• 用___前vs用___后
• ___年前的我vs现在的我
• ___块和___块的区别
```

### 清单型选题

```
• ___个相见恨晚的___
• ___款必买的___
• ___件提升幸福感的好物
• ___个___小技巧
• ___本改变人生的书
```

### 教程型选题

```
• 如何在___天内___
• ___分钟学会___
• ___步搞定___
• 0基础___教程
• 手把手教你___
```

### 测评型选题

```
• ___款___测评，这款最值得买
• 风很大的___到底值不值得买
• ___块vs___块，差的不仅仅是价格
• 网红___实测，真相是___
```

### 故事型选题

```
• 从___到___，我做对了什么
• ___天后，我终于___
• 被___改变的一年
• 那个___的我，现在怎么样了
```

## 五、选题验证方法

### 搜索验证

1. 打开小红书搜索关键词
2. 查看搜索下拉词（说明有人搜）
3. 查看相关笔记数量和互动量

### 爆款对标

1. 找到同选题的爆款笔记
2. 分析：标题、封面、内容结构
3. 找出可优化的点（差异化）

### 差异化切入

```
同选题，不同角度：

选题：防晒推荐
• 切入点1：敏感肌防晒（人群细分）
• 切入点2：平价防晒（价格细分）
• 切入点3：军训防晒（场景细分）
• 切入点4：防晒测评（形式细分）
```
